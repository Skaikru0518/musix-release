# Musix — releases

Desktop music player built on YouTube, with listening together and Discord status.
This repository only hosts the Windows installers; the app updates itself from here.

## Install

1. Open the [latest release](https://github.com/Skaikru0518/musix-release/releases/latest)
   and download `musix-<version>-setup.exe`.
2. Run it. Windows SmartScreen may warn because the app is not code-signed:
   click **More info → Run anyway**.
3. Sign in with your Google account (it must be added as a tester — ask the author).

After this, Musix checks for updates on its own and installs them when you restart it.
